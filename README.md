# Maestro Conceição

Site do Maestro Conceição (Projeto Conceiçando): composições, crônicas e músicas autorais.

Site estático: `index.html` + `img/` + `audio/`. Publicado na Vercel sem configuração.

Para adicionar uma música ao carrossel, acrescente uma linha na lista `MUSICAS` dentro do `index.html`.
